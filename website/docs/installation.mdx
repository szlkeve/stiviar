# Installation

## 1. Install the library

```bash
npm install your-lib-name
```

## 2. Install a schema validator

The library validates every response at runtime against a schema you provide. It's schema-library agnostic — use whichever one your team prefers.

**zod** (most common choice):

```bash
npm install zod
```

**valibot** (smaller bundle size, similar API):

```bash
npm install valibot
```

Either works with the library out of the box, since schemas are just passed in as plain values — there's no adapter or plugin step required.

## 3. Confirm React version

The hooks this library exposes rely on standard React hooks (`useState`, `useEffect`) and work with any React 18+ project. No special setup, no context providers, no wrapping your app in a special component.

## Peer dependencies recap

| Package | Required | Notes |
|---|---|---|
| `react` | Yes | 18+ |
| `zod` or `valibot` | Yes (one of) | Used to define and validate your schemas |

Once installed, head to [Getting Started](./getting-started) to register your first API state.
