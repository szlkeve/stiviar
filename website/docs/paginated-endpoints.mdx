# Paginated Endpoints

A paginated endpoint returns a page of results at a time, along with metadata about the total count and current position. This builds directly on the [dynamic endpoint](./dynamic-endpoints) pattern — `page` and `pageSize` are just params like any other.

## Defining a paginated response shape

A reusable generic type keeps every paginated endpoint's shape consistent:

```ts
// types.ts
export interface Paginated<T> {
  items: T[];
  page: number;
  pageSize: number;
  totalCount: number;
}

export interface Movie {
  id: number;
  title: string;
  year: number;
}

export interface PageParams {
  page: number;
  pageSize: number;
}
```

## Defining the schema

```ts
// schemas.ts
import { z } from "zod";
import type { Paginated, Movie } from "./types";

const MovieSchema = z.object({
  id: z.number(),
  title: z.string(),
  year: z.number(),
});

export const PaginatedMoviesSchema: z.ZodType<Paginated<Movie>> = z.object({
  items: z.array(MovieSchema),
  page: z.number(),
  pageSize: z.number(),
  totalCount: z.number(),
});
```

## Registering the endpoint

```ts
// api.ts
import { register } from "your-lib-name";
import type { Paginated, Movie, PageParams } from "./types";
import { PaginatedMoviesSchema } from "./schemas";

const BASE_URL = "http://localhost:3001/api";

export const api = register<{
  moviesPage: { type: Paginated<Movie>; params: PageParams };
}>({
  moviesPage: {
    url: (params) => `${BASE_URL}/movies?page=${params.page}&pageSize=${params.pageSize}`,
    schema: PaginatedMoviesSchema,
  },
});

export const useFetch = api.useFetch;
```

## Consuming it

```tsx
function MoviesList() {
  const [page, setPage] = useState(1);
  const pageSize = 20;

  const { data, isLoading, error } = useFetch("moviesPage", { page, pageSize });

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>{error.message}</p>;

  const totalPages = data ? Math.ceil(data.totalCount / pageSize) : 0;

  return (
    <div>
      <ul>
        {data?.items.map((movie) => (
          <li key={movie.id}>{movie.title} ({movie.year})</li>
        ))}
      </ul>
      <button disabled={page <= 1} onClick={() => setPage((p) => p - 1)}>
        Previous
      </button>
      <span>Page {page} of {totalPages}</span>
      <button disabled={page >= totalPages} onClick={() => setPage((p) => p + 1)}>
        Next
      </button>
    </div>
  );
}
```

Each time `page` changes, `useFetch` is called with new params — a new cache entry is used for that page, and previously visited pages stay cached, so paging backward doesn't re-fetch.
