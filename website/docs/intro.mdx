# Introduction

This library is a fully decoupled, declarative, type-safe API layer for your frontend.

You define the shape of your app's data once — a type, a validation schema, and a URL — and get automatic type safety, runtime validation, caching, and error handling for free. There's no codegen step, no versioning, no schema registry, and no requirement that your backend even be written in the same language as your frontend.

## The core idea

Every API state your app cares about is registered once, up front:

```tsx
export const api = register<{
  user: { type: User };
  movies: { type: Movies };
}>({
  user: {
    url: "/user",
    schema: UserSchema,
  },
  movies: {
    url: "/movies",
    schema: MoviesSchema,
  },
});

export const useFetch = api.useFetch;
```

From then on, any component can consume that state with full type safety and zero boilerplate:

```tsx
function Settings() {
  const { data, isLoading, error } = useFetch("user");
  return <p>Settings for {data?.name}</p>;
}
```

`data` is typed as `User | undefined`, validated at runtime against `UserSchema`, cached, and shared across every component that calls `useFetch("user")`.
